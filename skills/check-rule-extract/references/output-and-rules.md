# 输出工作簿与合并通用规则

> 供协调方按需加载的参考件：**合并生成工作簿（第 7 步）前读**，用于核对列的含义与填写规则、确认模板覆盖参数、判定逻辑类型与多条校验的表达。落盘片段的字段来源见 `extract-agent.md`；脚本参数与模板 JSON schema 见 `scripts/build_check_xlsx.py` 文档字符串。

## 一、内置通用模板（缺省，11 列，单表头）

产物为 **Excel 工作簿（.xlsx）**，单工作表 `Sheet1`，**每行一条管控逻辑**。列定义与填写规则：

| 列 | 表头 | 填写规则 |
|----|------|---------|
| A | 一级菜单 | 片段 `### 一级菜单：xxx`（无菜单体系时留空） |
| B | 二级菜单 | 片段 `#### 二级菜单：xxx` |
| C | 三级菜单 | 片段 `##### 三级菜单：xxx`（无三级菜单时留空） |
| D | 功能点 | 操作类型：保存/新增/删除/锁定/解锁/推送/作废… |
| E | 触发时机 | 操作前（默认；代码中前置校验均为操作前） |
| F | 校验位置 | 后端（默认）；若为前端 / 注解参数校验标「前端」 |
| G | 逻辑类型 | 数据校验 / 业务管控 / 审批流转 / 权限控制 / 计算规则 / 数据转换 / 其他 |
| H | 管控类型 | 管控（硬性拦截，默认）/ 提醒 / 询问 |
| I | 管控逻辑描述 | **核心列**。中文描述该条校验规则；白名单 / 特殊权限类条目**以角色导向描述**：写明「判定主体 + 条件 + 放行范围」，并按描述中的**权限点代码**从权限明细匹配取出**有权限角色**，格式「仅以下角色可操作：<角色1>、<角色2>…（权限点 `<权限点>`）」；明细表查不到该权限点时写「需权限点 `<权限点>`（权限明细表未查询到该权限点的角色配置，需人工确认）」 |
| J | 提示语 | 代码中异常 / 提示文案原文；无则不填 |
| K | 备注 | 留空（人工填写） |

**样式**：字体宋体 11；表头加粗、浅灰底 `FFC0C0C0`、细边框、水平垂直居中；数据行垂直居中、长文本列（描述 / 提示语）自动换行；冻结窗格 `A2`；列宽按内容适配（描述列较宽）。

## 二、模板覆盖（`--template <JSON>`）

项目需对接既有表格样式（如《xx收集表》）时，提供模板 JSON（schema 见 `scripts/build_check_xlsx.py` 文档字符串），可覆盖：表头行数（1，或 2+：2 时支持第 1 行分组提示 + 表头合并）、列头文本、列宽、字段写入列顺序、冻结窗格、表头底色、涉及系统列（填 √）。未传模板即用上表的内置通用模板，本技能不绑定任何项目专属列结构。

## 三、生成要求（合并口径）

1. 每行一条管控逻辑；同一操作的多条校验**拆分为多行**（菜单层级相同、功能点相同、描述不同）。
2. 未找到对应操作的校验**不占行**（不输出空的标题层级行）。
3. 管控逻辑描述**优先使用中文**：优先取自代码注释、异常提示文案、业务上下文推断；确实找不到中文描述时，用方法名 / 错误码等英文原文。
4. 白名单 / 特殊权限（权限注解、管理员判定、白名单配置、特殊单位 / 内部单位放行等）**必须**作为独立条目写入，逻辑类型=权限控制，描述以**角色导向**写（见上表 I 列），不遗漏权限信息。
5. **本册来源不可省略**：数据区末尾空一行，在 A 列写 `本册来源：{范围描述}（{追溯的 Controller / Service / Validator 等文件清单}）`，便于核对与复现，不占用数据区。

## 四、通用规则说明

### 操作定义（功能点 D 列）

- **保存 / 新增**：新增或编辑记录时的校验
- **删除**：移除记录前的校验
- **锁定**：将记录置为只读状态的校验
- **解锁**：将记录恢复为可编辑状态的校验
- **推送 / 发起、作废** 等：按实际操作类型填写功能点

### 多条校验的表达

- 原 markdown 模板中的「强制1 / 强制2 / 强制3」在 Excel 中**拆分为多行记录**：菜单层级相同、功能点相同，每行一条管控逻辑描述。
- 「仅管理员可操作」「需无后续业务数据」等约束同样作为独立行，逻辑类型分别归入「权限控制」/「业务管控」。

### 逻辑类型（G 列）

- **数据校验**：非空、重复、格式、存在性等
- **业务管控**：状态判断、上下游业务数据约束、锁定关系等
- **审批流转**：需审批 / 流程发起后才能执行
- **权限控制**：管理员判定、白名单、特殊单位 / 内部单位放行等
- **计算规则 / 数据转换 / 其他**：按实际归类

### 白名单 / 特殊权限（必须写入业务规则）

提取时凡遇到以下判定，一律作为独立「权限控制」条目写入 I 列，描述写明「判定主体（谁）+ 条件 + 放行范围」：

- 权限注解：`@RequiresPermissions` / `@PreAuthorize` / `hasPermission(...)`
- 管理员判定：`isAdmin` / 管理角色
- 白名单配置：`whiteList` / `isWhite` / `checkWhite` / 免校验名单
- 特殊单位 / 内部单位 / 指定机构放行
