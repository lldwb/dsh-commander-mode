# 路由表模板与填充说明

本文件是 `spec-route` 技能的参考件：**项目侧**按此模板把自家 `AGENTS.md` 的章节结构登记进来，之后每次查约定都按「场景 → 章节」直接定位，不必全文加载 `AGENTS.md`。

## 何时读本文件

- 首次为某项目建立规范路由时（按「填充步骤」产出项目自己的路由表）；
- 按段读取 `AGENTS.md` 时（照抄「读取指引」的命令写法）；
- 路由表与 `AGENTS.md` 实际结构不一致、需要校准时。

## 一、先登记权威源

| 项 | 内容 |
|---|---|
| 权威源 | `AGENTS.md`（项目根目录，唯一权威源） |
| 路径 | `<项目根>/AGENTS.md`（`CLAUDE.md` 只作指向，不作为约定正文来源） |
| 章节标题格式 | 例：`## <章节名>`（按项目实际格式填写，供 grep 用） |
| 章节总数 | `<N>` |
| 维护约定 | 约定变更请改 `AGENTS.md` 本身；本路由表只登记章节位置，不复制约定 |

## 二、路由表模板

每个场景一行；`场景` 用改任务时自然想得到的说法（越贴近实际提问越好），`章节` 是 `AGENTS.md` 里承载该约定的章节。

| 场景 | 章节 | 章节锚点标题（grep 用） | 该章关键约定（仅关键词，不复制正文） |
|---|---|---|---|
| `<场景 1：例 新增/修改持久层映射文件>` | `<章节名>` | `## <章节名>` | `<关键词 1>`、`<关键词 2>` |
| `<场景 2：例 定义异常与错误码>` | `<章节名>` | `## <章节名>` | … |
| `<场景 3：例 数据库表结构变更>` | `<章节名>` | … | … |
| `<场景 4：例 接口契约变更的影响面排查>` | `<章节名>` | … | … |
| `<场景 5：例 提交信息结构与类型>` | `<章节名>` | … | … |
| `<场景 6：例 分层与调用约束>` | `<章节名>` | … | … |
| `<场景 7：例 编码约定（日志、魔法值、数值计算）>` | `<章节名>` | … | … |
| `<场景 8：例 权限与鉴权>` | `<章节名>` | … | … |
| `<场景 9：例 构建与运行命令>` | `<章节名>` | … | … |
| `<场景 10：例 跨模块共用约定>` | `<章节名>` | … | … |

> 表不必求全：只登记**会被反复问到**的场景（提交规范、分层约束、持久层写法、异常体系、数据库变更、编码约定、构建命令这几类命中率最高）。遇到未登记的场景，按「读取指引」临时定位后**回填一行**，路由表随使用增长。

## 三、填充步骤

1. 取 `AGENTS.md` 的章节目录（grep 章节标题格式即可一次列出全部章节与行号）：

   ```bash
   grep -n "^## " AGENTS.md
   ```

2. 按上表逐行登记：场景 → 章节名 → 锚点标题（**与 `AGENTS.md` 标题逐字一致**，grep 才命中）。
3. 每个场景再扫一眼该章的小节标题，把最常用的约定关键词填进最后一列（关键词只作提示，不构成约定）。
4. 若存在**高频子规范速查**（常被同时问到的几章），在表尾补一行"高频组合"，如：`持久层 → 异常错误码 → 数据库变更 → 编码约定`。

## 四、读取指引（查约定时照此执行）

```bash
# 1) 定位章节标题，拿到行号（pattern 用路由表中的「章节锚点标题」）
grep -n "^## <章节名>" AGENTS.md

# 2) 只读该段：从命中的行号开始读，读到下一节标题前为止
#    在 DSH 中用 read 工具：file_path=AGENTS.md, offset=<起始行号>, limit=<该章行数>
```

- **不要**一次性 read 整个 `AGENTS.md`；章节很长时按小节再切一次。
- 章节内出现"见「某章节」"这类交叉引用时，按同法再定位一次，不做连锁全量加载。
- 在 DSH 中优先用 **grep 工具**（`pattern` + `path`）替代 shell grep。

## 五、输出格式

查完约定后按此结构回复，便于用户复核：

```
场景：<用户的任务场景>
权威源：AGENTS.md

命中的约定：
1. <约定原句或紧贴原意的摘录> —— `AGENTS.md:<行号>`
2. ...

关联章节（本次未展开）：
- <章节名> —— 若涉及 <条件> 需一并参照
```

最后一条固定写明：**"以上为 `AGENTS.md` 摘录，约定以 `AGENTS.md` 为准"**——提醒读的人约定归属，而不是这份回复。
